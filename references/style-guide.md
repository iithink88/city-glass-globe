# 视觉规范与提示词手册

本文件是技能的设计依据，供调整提示词或排错时查阅。常规出图只需按 `SKILL.md` 的工作流执行，无需通读。

## 1. 参考视觉规范

从《把一座城市装进玻璃球里，AI创意太有意思了！》一文的示例海报（郑州、清明上河园、万岁山、桂林、哈尔滨、北京）提炼：

| 维度 | 规范 |
|---|---|
| 画幅 | 竖版 3:4（示例 1080×1440；生图用 1024×1536 接近） |
| 主体 | 一只完整、圆润、居中的透明水晶玻璃球，占画面高度约 70%，绝不裁切 |
| 玻璃 | 有厚度、真实折射、边缘高光、映出窗格柔光；通透无气泡、无变形 |
| 底座 | 深胡桃木抛光圆形底座，木纹细腻；可带一块空白金色铭牌 |
| 球内 | 超精细微缩城市全景：地标 + 街巷 + 水系/山体 + 树木 + 极小尺度的行人与小吃摊；前中远三层，tilt-shift 景深 |
| 光线 | 球内暖黄灯火 + 球外柔和自然侧逆光；光比克制，整体温润 |
| 背景 | 暖米色／浅杏色纯色，浅景深柔焦；右上角一枝虚化梅花或玉兰作前景点缀；桌面柔和投影 |
| 氛围 | 商业产品摄影 / 文创纪念品广告大片，8K 超写实，不是插画、不是 3D 卡通 |
| 排版 | 左上大标题「如果把XX装进玻璃球」+ 细线 + 英文名 + 经纬度；左下 @署名；右下两句短文案；深棕色字 |

### 城市差异只换「内容」不换「形式」
- 桂林：漓江峰林、象鼻山、竹筏、米粉摊 → 突出自然风光
- 哈尔滨：索菲亚教堂、中央大街、雪与雾凇、暖橱窗 → 突出冬日氛围
- 北京：天坛、故宫红墙、胡同银杏、远处央视大楼 → 古今同框
- 郑州：二七塔、大玉米、烩面摊 → 老城烟火与新区天际线
- 上海：外滩、陆家嘴、黄浦江、石库门 → 天际线与弄堂

## 2. 提示词九段结构

`build_prompt.py` 输出的提示词按以下顺序组织，改提示词时保持这个顺序（模型对靠前的描述权重更高）：

1. 一句话总纲（画幅 + 物件 + 场景）
2. 【主体】玻璃球、底座、投影
3. 【球内微缩世界】地标清单 + 场景 + 前中远景 + 微缩质感
4. 【光线与季节】季节、色调、内外光
5. 【背景与构图】背景、花枝、留白、对称构图、产品摄影
6. 【必须遵守】负面约束（无文字、无水印、无第二只球等）

## 3. 为什么文字要后期叠加

图像模型生成中文几乎必然出现错字、乱码、缺笔画，尤其是「装进玻璃球」这类长标题和经纬度。因此：

- 生图提示词明确要求：画面不出现任何文字、字母、数字、招牌字、铭牌字、水印、logo；店招与铭牌留空白；左上和底部留白。
- 中文标题、英文名、经纬度、短句、署名由 `add_text_overlay.py` 用系统字体绘制，100% 正确、可改、可脱敏。
- 只有用户明确要求「纯图、不要文字」时，才跳过叠加步骤。

金色铭牌在示例图上有城市名，但本技能留空；如需铭牌文字，可用 `--panel` 之外的方式（例如在设计软件中另加），不要让模型写字。

## 4. 风格变体（`--style`）

| 值 | 效果 |
|---|---|
| `poster`（默认） | 标准暖米色文创海报 |
| `snow` | 冬日雪花玻璃球，屋顶覆雪、暖灯更浓 |
| `night` | 夜景万家灯火，深蓝夜空 + 暖黄光晕 |
| `ink` | 国风淡彩，青绿赭石、宣纸肌理（适合古城、山水城市） |
| `clean` | 极简棚拍，纯暖灰背景、无花枝、单一投影 |

变体可与城市自由组合，例如 `哈尔滨 --style snow`、`重庆 --style night`、`苏州 --style ink`。

## 5. 常见失败与修复

| 现象 | 原因 | 处理 |
|---|---|---|
| 球里冒出乱码汉字 / 假招牌 | 提示词未强调无文字，或用户加了含文字的参考图 | 确认用的是脚本产出的完整提示词；不要传 `--extra "写上城市名"` |
| 出现两只球 / 球体被裁切 | 主体约束被稀释 | 保持提示词末尾的【必须遵守】段落；`size` 用 `1024x1536`，不要用方图 |
| 玻璃像塑料或完全看不见 | 折射描述不足 | 在 `--extra` 追加「加强玻璃折射与边缘高光，球体轮廓清晰」 |
| 城市认不出来 | 地标太泛 | 用 `--landmarks` 给出 4–6 个具体地标；把城市补进 `cities.json` |
| 变成卡通 / 插画 | 写实关键词被覆盖 | 不要传 `--style ink` 以外的自定义风格；保留「商业产品摄影、8K 超写实」 |
| 文字压在玻璃球上 | 生图没留白 | 叠加时加 `--panel` 或 `--scale 0.9`；重生成时 `--extra "左上与底部大面积干净留白"` |
| 右下角出现「AI生成」平台水印，压住短句 | 平台自动叠加，提示词无法禁止 | 叠加时加 `--hide-watermark`（裁掉底部 6% 桌布留白，无痕且更接近 3:4）；短句默认已上移到 0.895H 避开水印区 |
| 提示词换成英文后效果更稳 | 模型对英文更敏感 | 用 `<城市>_prompt_en.txt` 再生成一次，对比择优 |

## 6. 批量与复用

- `build_prompt.py 北京 上海 西安 --outdir <目录>` 一次生成多套提示词，之后逐城调用生图与叠加。
- 每城一个子目录，命名 `<城市>_海报.png` / `<城市>_prompt.txt` / `<城市>_meta.json`，便于成套交付。
- 教学用途：可让学生先填 `--landmarks` 做「家乡地标调研」，再生成海报，最后比对 AI 是否画对地标，作为信息科技/地理课的图像识读素材。
- 文创用途：海报只作创意效果展示，落地产品需另行核对地标授权与商用规范。

## 7. 分享与脱敏

- 署名默认 `@你的名字`，交付前按用户要求替换（`--signature`）。
- 不把任何 API Key、账号、内部路径写进技能文件；对外分享只提供 `SKILL.md`、`scripts/`、`references/`。
- 参考海报来自公众号文章，仅用于归纳视觉规律，不把原图打包进技能或作为商用素材。

## 8. 扩展城市库

`cities.json` 每个条目字段：

```json
"城市名": {
  "en": "英文名",
  "aliases": ["别名"],
  "coords": "纬度°N, 经度°E",
  "landmarks": ["地标1", "地标2", "地标3", "街市/自然元素"],
  "scene": "一句场景描述",
  "season": "季节或光线",
  "palette": "三个主色",
  "slogan": "一句原创短句"
}
```

未收录的城市会自动走「通用地标模板」仍能出图，但辨识度较低，建议补录。涉及中国香港、中国澳门、中国台北时，英文按 `Hong Kong, China` / `Macao, China` / `Taipei, China` 书写。
